Callers supply honest fixture data and persistence. `queue-detail.tsx` demonstrates controlled actual shadcn Dialog/Button/Textarea composition with application-owned failed-save draft/retry and cancel. These small examples are source sketches, not preapproved product scenarios or visually accepted browser results. Their record/hash/fixture state is explicit in the library manifest.

No copied Mobbin imagery, logos, customer data or external source assets. Original compositions retain [original MIT notice](../../licenses/ORIGINAL-MIT.txt). Upstream UI components preserve their separate [shadcn MIT notice](../components/react-shadcn/LICENSE.md).
