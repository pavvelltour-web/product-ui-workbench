# Отправные точки для исследования

Это ссылки для нового поиска, а не набор уже просмотренных и измеренных экранов. Просмотрите конкретный источник и состояние самостоятельно. Чужие изображения в пакет не включены.

| Источник | Что искать |
|---|---|
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) | Платформенные принципы и материалы; отдельно проверять реальные рабочие экраны |
| [Material Design](https://m3.material.io/) | Смысловые роли цвета, типографики и компонентов |
| [Fluent 2](https://fluent2.microsoft.design/) | Плотные рабочие интерфейсы, состояния и доступность |
| [Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started) | Реальные контролы и тематизация |
| [shadcn/ui](https://ui.shadcn.com/docs) | Исходники компонентов и библиотечные контракты |
| [Pinterest](https://www.pinterest.com/) | Подбор направлений с переходом к оригинальному автору |
| [X](https://x.com/search-advanced) | Авторские разборы, свежие работы и демонстрации состояний |
| [Dribbble](https://dribbble.com/) | Визуальные исследования, а не доказательство UX |
| [Behance](https://www.behance.net/) | Серии экранов, кейсы, типографика |
| [Mobbin](https://mobbin.com/) | Рабочие экраны/flows при наличии законного доступа; сервис необязателен |

Практический порядок и запросы: [поиск без платных библиотек](REFERENCE_SEARCH.md). Официальные способы установки навыков: [Codex](https://learn.chatgpt.com/docs/build-skills), [Claude Code](https://code.claude.com/docs/en/skills).
